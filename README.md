# Web-based-Music-Quiz-
This is a free to use template I made as a project for a class. 
It's a basic music quiz where the user guesses a song from a 5 second randomly selected clip from a random song. 

Programming Languages:
- HTML
- PHP
- SQL (if you still intended to use the login system)

IDE used: VSCode with the basic HTML extensions

XAMPP is also required to run the project as it was web based and requires a login system. 

XAMPP download link: https://www.apachefriends.org/download.html

Issues:
- Game Screen is locked behind a login screen for which you must set up your own SQL server (unless you can rewrite the login system)
- Guest Play is available but not sure if it works without the SQL server active or not
- Songs are still required to be installed locally and added manually as an array inside game.php
